# Retainer Pro marketing site

Public marketing site for Retainer Pro, owned by Legal Fusion Hub, LLC. Retainer Pro answers the call, qualifies the lead, and books the consultation that turns a bankruptcy inquiry into a retained client.

## Stack

- Next.js 16 App Router
- React 19 and TypeScript
- Tailwind CSS 4
- Motion
- Self-hosted variable fonts
- Vercel deployment

## Develop

Requires Node.js 24 or later.

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Verify

```bash
npm run lint
npm run typecheck
npm run build
```

## Book a demo

**Book a demo** CTAs go to the three-option contact section on Contact (`/demo#contact-options`): send an inquiry, call us, or book a live demo. The Contact nav item still opens `/demo`.
